# ExtroDevModuleLoader
Generated by [ExtroRojo](https://github.com/ExtroDevGit/rojo_extrodev) 0.1.0 (`loader` template).

## Getting started

```bash
extrorojo build -o "ExtroDevModuleLoader.rbxlx"
```

Open `ExtroDevModuleLoader.rbxlx` in Roblox Studio, then:

```bash
extrorojo serve
```

## The Module/Component loader

`ServerScriptService.ModuleLoader` and `StarterPlayerScripts.ModuleLoader` each auto-load
two folders, `Modules` and `Components`, using the shared `ReplicatedStorage.ModuleLoader.Loader`.

- **Modules** (`Modules/*.luau`): required automatically at startup. Do your setup at the
  top level of the script, or return a table with an `Init` function to have it called
  right after requiring.

- **Components** (`Components/*.luau`): named `<Tag>_Server` / `<Tag>_Client`, return a
  table with a `Start(instance)` function (and optional `Stop(instance)`). `Start` runs on
  every instance CollectionService-tagged `<Tag>`, now or later; `Stop` runs when an
  instance loses that tag (including being destroyed).

Example: tag a Part `NPC` and `Components/NPC_Server.luau`'s `Start` runs on it automatically
-- see that file and `Modules/Test.luau` for the included examples.

For more, see the docs bundled with the [ExtroRojo VS Code extension](https://github.com/ExtroDevGit/vscode-rojo-extrodev).
